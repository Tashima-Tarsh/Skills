# Engineering skill and tool registry

> Central index of external GitHub projects. A link is not an installed skill, an endorsement, or a compatibility guarantee. Verify repository availability, license, maintenance, releases, and security before importing anything. Never execute upstream install scripts automatically.

**Usage:** Read `AGENTS.md`, then `skills/skill-router/SKILL.md`; pick only the sources needed for the task. Actual SKILL.md bundles require individual inspection. Frameworks and binaries should be used as tools rather than loaded as textual skills.

## Maintenance checklist

- Confirm the GitHub repo exists; note redirects, archival status and canonical owner.
- Inspect license, release history, code execution, network access and hooks.
- Pin a reviewed commit SHA in any downstream installed copy.
- Capture source URL, commit, license, tool/skill classification and last check in a lockfile or metadata registry.
- Treat descriptions as routing hints only, not proof of capabilities.
- Verify changes with relevant tests and never claim unexecuted tests passed.
